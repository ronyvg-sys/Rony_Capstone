# Project ABC — Governance

## Governance Structure

### Weekly Project Governance
Reviews:
- Schedule
- Risks
- Issues
- Dependencies
- Testing
- Financials

### Steering Committee
Reviews:
- Critical risks
- Major decisions
- Scope changes
- Release readiness
- Escalations

## Risk Escalation
Critical risks must be escalated to the Steering Committee.

## Issue Priority
Severity 1 issues receive immediate attention and are prioritized over lower-severity issues.

## Change Control
Any change affecting scope, schedule or production date requires impact assessment and formal approval.

## Reporting
The Project Manager publishes a weekly status report and maintains the risk, issue and dependency registers.
